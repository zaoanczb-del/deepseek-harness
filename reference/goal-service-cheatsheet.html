GoalService 速查表

一句话：每个 Session 最多一个当前 Goal；持久状态来自 Session 日志，自动续行资格只存在于当前进程。

状态的三种表示

类型包含什么用途
GoalSnapshotid、revision、objective、phase、maxGoalRounds每次非 clear 变更写入日志的完整快照
GoalProjectionSnapshot + roundsStarted + 时间从持久事件折叠出的当前状态
GoalViewProjection + activation运行中调用者看到的完整视图

生命周期

create → active
active → pause → paused
active → block → blocked
active | paused | blocked → complete
active | paused | blocked → resume → active
任何当前状态 → clear → 无当前 Goal

activation 是独立维度：armed 允许 driver 自动续行，disarmed 不允许；它不写入 Session 日志。

session.append('goal/change')

投影同步折叠事件，activation 与日志序号对齐

三个容易混淆的事实

  • revision 只由 Goal 变更推进；准入 Round 只推进 roundsStarted。
  • clear 的投影是 null，日志中仍保留带下一 revision 的 tombstone。
  • 恢复后持久的 phase 可以仍是 active，但 activation 初始为 disarmed。
