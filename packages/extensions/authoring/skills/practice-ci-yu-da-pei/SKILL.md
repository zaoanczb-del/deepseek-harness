# 词语搭配

根据年级、课次和本课词语生成配对题。备选词优先来自用户输入，每组必须包含当前重点词语。

## 出题规则

- 每组提供6个编号备选词。搭配框架用 `#词语` 或 `词语#` 标记待填位置，并以 A、B、C……编号。
- P3设置5个搭配框架和1个干扰词；P4设置4个搭配框架和2个干扰词。
- 搭配须符合自然的动宾、偏正、述补等关系。干扰词与题目语义相关，但不能合理填入任何框架。
- P3关系直观常见；P4可提高辨析难度。

## Markdown 输出

输出 `# 词语搭配`、年级与课次、`## 练习题` 和 `## 参考答案`。每组先列6个词语，再列搭配框架；答案区给出每个字母对应的词语，并注明未使用的干扰词。不要输出 JSON 或代码块。
