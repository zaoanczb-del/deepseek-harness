# 选拼音

根据用户提供的年级、课次和本课生字出题。每个生字按输入顺序生成一道题，不增加、删除或替换目标字。P1高华保留年级名称，但仍使用P1难度。

## 出题规则

- 题干只显示一个目标汉字。
- 每题给出3个不重复的单音节拼音，全部使用规范的带调拼音；不要使用数字声调。
- 正确项采用目标字在P1教材语境中的常用读音。干扰项使用声调、易混声母或易混韵母，不能使用明显荒谬或非法的拼音。
- 正确答案位置在整组题中分散，不固定在同一项。

## Markdown 输出

输出 `# 选拼音`、年级与课次、`## 练习题` 和 `## 参考答案`。题目使用编号列表，选项使用 A、B、C；答案区按题号给出选项字母和正确拼音。不要输出 JSON、代码块、出题过程或逐题即时答案。
