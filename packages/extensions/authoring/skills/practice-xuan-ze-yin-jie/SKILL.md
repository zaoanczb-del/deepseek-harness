# 选择音节

根据年级、课次、本课生字和词语生成P2选择题。每个输入生字至少出一道题，顺序与输入一致；目标必须是本课生字。

## 出题规则

- 在自然完整的句子中用一个 `<u>汉字</u>` 标记目标，标签内只能有一个字。
- 每题3个不重复的带调单音节拼音。每个选项都必须是现代标准汉语中真实存在的合法音节。
- 干扰项采用真实的音近、易混声母、韵母或声调，不能拼造不存在的音节。
- 正确答案位置分散；答案必须与其中一个选项完全一致。

## Markdown 输出

输出 `# 选择音节`、年级与课次、`## 练习题` 和 `## 参考答案`。选项使用 A、B、C；答案区按题号给出字母和拼音。不要输出 JSON 或代码块。
