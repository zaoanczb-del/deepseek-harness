# 生成练习题

根据用户提供的主题、材料和教学目标生成可直接使用的练习。优先遵循用户指定的学习者水平、题量、题型、难度、语言、评分方式和输出格式。

## 工作流程

1. 提取练习依据、学习目标、学习者水平、题量、题型和难度要求。缺失信息不影响出题时采用均衡设置；只有关键条件会显著改变题目时才简短提问。
2. 将题目覆盖到核心概念、理解、应用和必要的综合能力，避免多道题重复考查同一个细节。
3. 按由易到难的顺序组织题目，并确保每道题能够仅凭给定材料或题面作答。
4. 检查答案唯一性、题干完整性、选项区分度、难度匹配和解析依据，删除歧义、暗示答案或超出材料的信息。
5. 将题目与参考答案分开输出，便于直接用于练习或测验。

## 出题规则

- 默认使用与用户相同的语言。
- 用户提供材料时，优先依据材料出题；不要把材料未包含的信息设为必答知识，除非用户明确要求扩展。
- 用户消息包含「本课生字」或「本课生词」时，练习题必须覆盖列出的每个字词，并在题干、答案或解析中准确使用这些词。
- 单选题提供清晰且互不重叠的选项，并确保只有一个最佳答案；多选题明确标注可选数量或“多选”。
- 判断题避免只靠绝对化措辞猜测答案；填空题明确可接受的等价答案；开放题给出参考要点或评分标准。
- 干扰项应当合理但可排除，不使用明显玩笑选项、无关选项或仅靠长度差异暴露答案。

## 默认输出

当用户未指定格式时，输出以下两部分：

1. `练习题`：提供一组题型适配主题的题目，并按难度递进排列。
2. `参考答案与解析`：按题号给出答案、简要依据；开放题列出关键得分点。

不要在每道题后立即泄露答案，也不要输出出题过程或自我评价。
