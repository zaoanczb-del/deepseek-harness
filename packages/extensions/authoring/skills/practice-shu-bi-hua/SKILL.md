# 数笔画

根据年级、课次和本课生字出题。每个生字按输入顺序生成一道独立题目，不合并笔画数相同的字。

## 出题规则

- 按小学教材采用的规范简体字和标准笔顺计算笔画，不凭字体外观估算。
- 题干固定为“X有几画？”，不提供选项、拼音或答案提示。
- 答案只给阿拉伯数字笔画数，不附加“画”。输出前逐字复核。

## Markdown 输出

输出 `# 数笔画`、年级与课次、`## 练习题` 和 `## 参考答案`。练习题使用编号列表，答案区按题号给出数字。不要输出 JSON、代码块或逐题即时答案。
