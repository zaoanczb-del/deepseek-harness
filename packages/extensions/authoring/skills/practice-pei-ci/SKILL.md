# 配词

根据年级、课次、本课生字和词语生成音节配词题。每个不重复的生字按输入顺序出一道题；优先选择包含该字的本课双字词，没有合适词语时才使用P1常用双字词。

## 出题规则

- 将双字词转换为标准拼音，只隐藏一个音节，以 `#第二音节` 或 `第一音节#` 表示；整组题交替隐藏左右位置。
- 每题3个不重复的单音节拼音选项。正确项是缺失音节，干扰项使用声调、易混声母或韵母。
- 使用带调拼音；轻声可不标调，`j/q/x` 后的 ü 按规范省略两点。
- 每个目标生字必须出现在对应双字词中，且只有一个选项能正确补全词语。

## Markdown 输出

输出 `# 配词`、年级与课次、`## 练习题` 和 `## 参考答案`。每题注明目标词语，列出含 `#` 的拼音组合及 A、B、C 选项；答案区给出选项字母、缺失音节和完整目标词。不要输出 JSON 或代码块。
