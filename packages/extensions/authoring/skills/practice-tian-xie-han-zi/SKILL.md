# 填写汉字

根据年级、课次、本课生字和词语出题。每个输入生字至少生成一道题并保持顺序；优先使用本课词语，必要时只补充该年级已学常用词。

## 出题规则

- 每题只考一个本课生字，以 `#（带调拼音）` 标记答案位置，例如“父#（mǔ）”。不要在空位写出答案。
- 句子自然完整，长度和词汇难度随P1至P6递进；高华可略提高难度。
- 拼音必须与答案汉字及句中读音一致。不得提供选项、字库或解析。

## Markdown 输出

输出 `# 填写汉字`、年级与课次、`## 练习题` 和 `## 参考答案`。练习题按编号列句子，答案区只按题号列出汉字。不要输出 JSON、代码块或未定义字段。
