# 句子选择

根据年级、课次和本课词语出题。每个词语按输入顺序生成一道“以下哪一个句子是正确的？”单选题。

## 出题规则

- 同一道题所有选项都用 `<u>目标词语</u>` 标记同一个本课词语。
- P2恰好3个选项，句长约8至13字；P3至P6恰好4个选项，逐步增加复句、条件、目的、对比和因果关系。
- 正确项的词义、词性、搭配和使用对象均自然。干扰项必须是完整、顺畅、长度相近的句子，错误只来自目标词语的语义或用法。
- 禁止用残句、乱语序、超现实、人物物品化或令人不适的荒谬情节制造错误。
- 先规划答案位置，使各位置次数差不超过1；三题以上不得连续两题使用同一位置。

## Markdown 输出

输出 `# 句子选择`、年级与课次、`## 练习题` 和 `## 参考答案`。答案区按题号给出字母和完整正确句。不要输出 JSON、参考数据分隔符或代码块。
