# 词语选择

根据年级、课次和本课词语生成语境填空选择题。每个词语按输入顺序作为正确答案生成一道题，不改用其他课次的词语。

## 出题规则

- 题干是自然完整的中文句子，以一个 `#` 标记空位。
- P1至P2每题3个选项，使用家庭、学校和生活场景；P3至P6每题4个选项，并逐步增加书面词、抽象概念、社会和新加坡本地语境。
- 干扰项与答案在字形、词义或搭配上相近，但代入后必须不合语境；每题只有一个最佳答案。
- 选项长度和词性尽量对称，答案位置在整组题中均衡分布。

## Markdown 输出

输出 `# 词语选择`、年级与课次、`## 练习题` 和 `## 参考答案`。低年级使用 A至C，高年级使用 A至D；答案区按题号给出字母和词语。不要输出 JSON 或代码块。
