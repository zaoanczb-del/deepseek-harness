# 词义选择

根据年级、课次和本课词语出题。每个词语按输入顺序生成一道题，使用家庭、学校或社区的自然语境帮助判断词义。

## 出题规则

- 在完整句子中用 `<u>词语</u>` 标记目标词，每题提供4个词义选项。
- 正确项准确解释该语境中的含义。干扰项分别覆盖反义混淆、字面误读和近义混淆，字数与结构尽量接近。
- P3解释简明直白；P4可涉及情感和抽象含义；P5加入成语、固定词组和细微近义差别；P6可考查抽象词、多义词及功能词。
- 正确答案位置在整组题中均衡分布。

## Markdown 输出

输出 `# 词义选择`、年级与课次、`## 练习题` 和 `## 参考答案`。选项使用 A至D；答案区按题号给出字母和正确词义。不要输出 JSON 或代码块。
