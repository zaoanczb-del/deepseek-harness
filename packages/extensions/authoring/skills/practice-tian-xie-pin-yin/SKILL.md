# 填写拼音

根据年级、课次、本课生字和词语生成P2练习。每个本课生字至少出一道题并保持输入顺序；优先使用本课词语组成句子。

## 出题规则

- 每题用一个 `<u>汉字</u>` 标记目标，标记内只能有一个本课生字。
- 句子自然、完整，符合新加坡P2学生程度。
- 答案只写该字在句中的完整带调拼音，不含汉字、数字声调、括号、空格或标点。
- 不提供选项、字库或答案解析。

## Markdown 输出

输出 `# 填写拼音`、年级与课次、`## 练习题` 和 `## 参考答案`。答案区按题号列出拼音。保留题干中的 HTML 下划线标签；不要输出 JSON 或代码块。
