# 组词成句

根据年级、课次、本课生字和词语出题。优先使用本课词语，可补充必要的常用虚词、量词和标点，但不改变本课考查重点。

## 出题规则

- 每题保留一个不编号的句首词，其余词语以 ①②③……连续编号并打乱；双字词不得拆开。
- P1一般提供3至4个编号词；P2至P4提供5至6个；P5至P6提供5至7个并可使用较复杂句式。
- 题目必须能组成完整、自然且尽量唯一的句子。答案只写编号顺序；多个同样成立的答案用 `|` 分隔。
- 不允许答案为完整连续递增序列，题目中不得出现 `#`、答案或解释。

## Markdown 输出

输出 `# 组词成句`、年级与课次、`## 练习题` 和 `## 参考答案`。答案区按题号给出编号顺序，并可在括号中写出还原后的完整句子供教师核对。不要输出 JSON 或代码块。
