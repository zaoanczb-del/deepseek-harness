# 拼音选择

根据年级、课次和本课词语出题。每个词语按输入顺序生成一道题，在贴近新加坡小学生家庭、学校、社区或本地生活的句子中考查词语拼音。

## 出题规则

- 目标词语使用 `<u>词语</u>` 标记。拼音选项中的两个音节用全角空格分隔并使用带调字母。
- P2提供3个选项；P3至P6提供4个选项。难度随年级提高，干扰项逐步更接近。
- 每题干扰项至少覆盖声母、韵母、声调或形近字读音中的两类混淆；所有拼音必须规范且不重复。
- 正确答案位置随机且整体分散；同一目标词重复练习时保持选项和答案一致。

## Markdown 输出

输出 `# 拼音选择`、年级与课次、`## 练习题` 和 `## 参考答案`。低年级使用 A至C，高年级使用 A至D；答案区按题号给出字母和正确拼音。不要输出 JSON 或代码块。
