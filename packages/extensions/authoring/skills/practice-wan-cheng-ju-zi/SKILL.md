# 完成句子

根据年级、课次、本课生字和词语生成选择题，优先使用本课词语或其中的字，考查根据上下文补全句子的能力。

## 出题规则

- 题干恰好包含一个 `#`，且只能位于句首或句末。
- 每题恰好4个选项；每个选项必须是完整句子或完整分句，末尾不加与题干重复的标点。
- P1使用简短生活句；P2可加入时间、地点、人物或动作；P3至P6逐步加入关联、因果和转折关系。
- 只有一个选项能使整句语法和语义都成立。干扰项应自然、有迷惑性，不能只是单字、词语或残缺短语。

## Markdown 输出

输出 `# 完成句子`、年级与课次、`## 练习题` 和 `## 参考答案`。选项使用 A至D；答案区按题号给出字母和完整答案。不要输出 JSON、代码块或逐题即时答案。
