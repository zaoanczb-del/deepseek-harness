# Agent Note: 插件自有的创作目录

Status: implemented

[English](2026-08-24-authoring-mode-plugin.md) | 中文

## 问题

教材故事编写、练习题生成，以及「好朋友」「知识画报」「知识报」刊物格式需要在输入区旁提供明确选择。增加固定 InputBar 参数会把产品特定内容放进通用对话外壳。若 UI 与模型指引分散在不同 preset 下，所有权也会分裂；若使用一个合并的 Story 提示词，每次请求都会附带其他刊物无关的格式规则。

## 决策

横跨 Host 与浏览器的 `@deepseek-ai/dsh-client-ui-authoring` 插件拥有 Web 选择器和二十个内置 skill。Host 端在 Standard preset 作用域挂载隔离的打包 Skill provider；浏览器端向 `conversation.input.left` 追加一个列表条目，并先查询当前会话的 `skill.list`，再显示可用选项。

「新朋友」「新天地」「新列车」共用通用 `story` skill。故事流程依次选择普通华文或高级华文年级，以及来自 `ezhishi_words.csv` 的课次；确认后写入自然语言 `/story` 请求及该课生字生词。[简洁的年级感知 Story 决策](../simplification/2026-08-26-concise-grade-aware-story-skill.zh.md)拥有这些指引。

「同步练习题」提供 LangMind 的十四种题型。每种题型映射到一个专用 skill，并保留原有适用年级范围。选择题型后，普通华文和高级华文年级会缩小到该范围，再沿用相同的 CSV 课次目录。确认后写入该题型的 `/practice-*` token，以及「生成内容」、年级、课次和相应 LangMind 提示词所需的生字、词语或两者。每个 skill 保留题目构造和校验规则，但把 LangMind JSON schema 改为可读的 Markdown 练习区和独立答案区。通用 `practice` skill 仍可供手动请求调用，但不再是选择器的同步练习目标。

「好朋友」「知识画报」「知识报」保留 LangMind 刊物选项，不显示年级、课次或词表字段。「好朋友」把「欢乐故事 / 欢乐儿童」映射到两个独立 skill；「知识画报」把「故事园地」映射到一个 skill，并由请求选择「哈比系列 / 动物寓言」；「知识报」把「故事空间」映射到一个 skill。每个专用 skill 只包含该刊物的受众、结构、篇幅、练习和 Markdown 输出规则，不包含 LangMind 的 JSON 序列化指令。确认后写入专用 skill token 以及从相应 LangMind 流程提取的可编辑默认请求。

草稿仍是模型可见且可持久化的选择状态。重新选择会移除已识别的插件生成调用，并保留其余用户提示词。提交仍沿用现有显式 skill 流水线：`dsh-tool-skill` 识别开头字面量，并且只注入所选 `SKILL.md`；本插件不增加调用协议或会话事件。

## 考虑过的替代方案

**把选择器放进通用 InputBar。**不采用，因为现有列表 slot 已支持有序的插件自有控件，无需让对话外壳理解产品目录。

**让六种类型全部使用年级和课次流程。**不采用，因为三个刊物已经隐含 P1–P2、P3–P4 和 P5–P6 受众，LangMind 为它们提供刊物子选项，而非课文字词。

**把所有刊物规则加入通用 Story skill。**不采用，因为每次请求都会注入互斥结构和大量无关提示词。专用 skill 能明确所选格式，并把其他刊物指引排除在该次请求之外。

**把所有同步练习规则加入通用 Practice skill。**不采用，因为十四种格式的适用年级、词表输入、选项数量和校验规则各不相同；所选请求不应注入其他十三种格式。

**保留 LangMind JSON 输出。**不采用，因为本应用直接渲染助手 Markdown，且没有练习或刊物 JSON 渲染器。迁移后的 skill 仍以 Markdown 保留题目、选项和答案。

## 测试

聚焦草稿测试固定练习词表字段映射、练习和刊物请求替换、用户文本保留、token 边界及选择恢复。组件测试固定三个教材范围的练习目录和年级筛选、各刊物条件控件、专用调用、目录失败行为及阶段变化时关闭。Host 生命周期覆盖证明二十个 skill 均可注册和 dispose。无密钥 Web 场景对组装后的选择器进行快照，并用 CSV 词表生成真实 skill 请求。

## 后果

通用输入框保持不变，一个插件从 UI 选择到模型指引拥有完整创作目录。练习和刊物请求只增加一个所选格式 skill；草稿包含用户也能手动输入的相同调用，因此选择保持透明。浏览器固定目录仍需配置或 skill 元数据通道，部署才能替换练习范围、刊物名称、选项或默认请求。
